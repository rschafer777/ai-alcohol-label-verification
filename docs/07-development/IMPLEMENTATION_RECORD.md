## Implemented data movement

The browser owns only selected `File` objects, lifecycle-managed previews, unconfirmed group edits, and active batch state. The API streams admitted content to a controlled spool, the worker reads local files, and cleanup removes spool content at every terminal path. Result persistence copies admitted source panels to an opaque history directory only after a successful result. SQLite stores immutable result JSON plus mutable reviewer disposition fields. Every record is assigned to a high-entropy browser scope that is enforced by every history query. It stores the reference used for the comparison: the label-derived draft in the label-first flow, or the application values the reviewer entered, whose provenance is shown in the history drawer.

The UI receives original dimensions and polygons. Image display uses an SVG view box equal to original dimensions, so resized presentation does not change evidence alignment. Historical images reuse the same coordinate contract.

Every admitted analysis returns the complete 24-row registry. When beverage type is unresolved or conflicting, type-dependent rows remain Review rather than selecting a family silently. These results stay usable for human disposition and are retained in history as Type uncertain. A wine alcohol range read from the label cannot validate itself; a conforming visible range remains Review until a trusted actual value is supplied.

OCR lines from every view of a panel are fused by region before candidate extraction: boxes that share most of their vertical extent and most of the narrower box's width are one printed line, and the fullest confident reading represents it while its typography metrics come from the highest-resolution view. Crop fragments therefore cannot become extra candidates or duplicate warning sentences. Panel readability is decided after the first read from the count and confidence of the lines OCR returned, not from a global sharpness statistic, so a soft render with a clean warning is readable and a blank capture is not. The government warning and any missing field are then re-read from an enlarged crop of the region the first pass located.

Decoded panels pass through a strict full-frame visual-equivalence gate before OCR. Equivalent cross-format files retain their own panel records and expose `duplicateOfPanelId`, while only the canonical panel creates OCR and recovery views. The gate does not use filenames, product identity, expected fields, or oracle data. Automated coverage uses equivalent and distinct arrays to prove that only the equivalent panel is deduplicated. The governed integration validator finds a cross-format equivalent pair from pixels alone, submits it through the production multipart API, and records the retained panels, duplicate linkage, source hashes, latency, and worker lifecycle in machine-readable evidence.

The worker caches no more than 2,048 OCR outputs keyed only by decoded view shape, pixel type, and pixel digest. It clears the cache at initialization. Filenames, product identities, expected values, and test-oracle data never influence a cache key or extracted value. Confirmed batch groups can therefore reuse the exact pixels already read during grouping without creating product-specific behavior.

## Evidence reading and decision implementation

OCR runs once per panel on a working image of at most 2.07 megapixels, then re-reads the government warning and any missing field from an enlarged crop of the region it located; at most three focused crops per request, warning crops first. Boxes from several views are fused by region only when their line heights agree and their texts nearly agree, so a small line inside a tall box and two distinct lines that happen to overlap keep their own places, while a duplicate detection of one line within a single view is fused. Every line keeps stroke width, letter height (the upper quartile of connected-component heights), gray-level range, and a WCAG luminance contrast ratio measured on the view that read it.

Candidate extraction repairs glued class words such as "OrganicVodka" and "GRAPEWINE", tolerates OCR-damaged units and role words such as "12 FL. 0Z", "Alc./Vo", and "brewed and bottld by", and recovers compact numeric runs such as "750ML40%ALCVOL 80PROOF". Split producer phrases may continue across adjacent lines. A country vocabulary constrains origin phrases, domestic city and state lines are not treated as country-of-origin statements, same-family class readings are collapsed, addresses are excluded from appellation candidates, and brand prominence excludes certification badges, dated establishment copy, location prefixes, and lines that are mostly digits. When a graphical brand mark is not read directly, a label-domain candidate may supply the visible brand token while retaining the original URL evidence. Beverage type can use class, producer, alcohol, and proof signals, but unresolved or conflicting signals remain Review.

The comparison layer compares the warning word for word, treats letter case, spacing, and glued clause markers as OCR artifacts, routes every other punctuation difference to the reviewer with the marks named, and rejects only on a missing sentence, an omitted statutory word inside a cleanly read statement, replacement language, or clear word substitutions that outnumber the OCR slips. Each panel carrying the warning is evaluated separately. A complete exact read outranks a partial read, and complementary partial reads can confirm statutory words only as a Review result that still requires punctuation confirmation. Type weight is decided by the heading-to-body stroke ratio, contrast by two agreeing measurements, and neither weight, separation, continuity on a garbled read, nor the ink-density heuristic can reject on its own. When application values are entered, they are searched across every readable line, but the search can only rescue an extraction failure, never a rule-format or placement failure, and a percentage counts only in alcohol context. A decoder-unreadable panel that OCR still reads at length keeps its fields and stays a review item. The physical type-size row is informational because a photograph carries no scale.

Before multipart upload, the frontend decodes JPEG, PNG, or WebP files with browser EXIF orientation, proportionally brings oversized images below the pixel cap with headroom, and steps through bounded JPEG quality and size reductions until the byte cap is met. If browser decoding is unavailable, the original file reaches the API and the server returns the governed side-by-side limit details. Server admission remains authoritative in all cases.

The statement is read on every submitted image that carries it; the comparison keeps the best-read image and, failing a complete read on one image, confirms statutory words across images as a review item. The browser brings photographs within the per-image pixel and byte limits before upload (EXIF orientation applied, proportions kept, JPEG re-encoded down a quality ladder), so evidence coordinates refer to the uploaded image the reviewer sees. The evidence viewer zooms with the mouse wheel about the point under the cursor, pans by dragging once enlarged (and by arrow keys), and resets from the zoom readout; the view switcher sits at the head of the checks with icons and a label so a reviewer can see that the layout can change. The batch grouping step tells the reviewer how many products are confirmed and how many still need a decision, filters the wall to those cards, confirms the remaining suggestions in one step, and states next to the run button why it is locked; the grouping tools carry tooltips that say what each does and when it is available.

An independent architecture review of the multi-image work found six ways a real label defect could be reported cleaner than before it, and the corrections are in place: a name that carries a style word ("Saison House") stays a brand candidate because only a line headed by a class word, made of designation vocabulary, or describing composition is a class statement; a designation set in sentence case is the class, and only a sentence with words outside the designation vocabulary is copy; the read lines of the statement travel with the observation, so a word fragment or a missing word counts as an edge cut only at the start or end of a read line and the same difference inside a line is a substitution or an omission; an edge-cut opening must continue with "According to the Surgeon" and never outranks a heading read elsewhere on the image; a fragment that leads alone judges the wording it shows and reports the heading's weight and the block's separation as outside the image; a second image cannot confirm away a word that one image read differently, and two complete reads that disagree on a word are a review item naming the disagreement, while a read that merely dropped words still yields to a clean read. A zero net-contents quantity, a misread digit, is no longer a candidate.

The operator's own store photographs (221 images at 300 pixels per inch, up to 11.5 megapixels, most of them dense back labels on curved glass) then exposed three ways a compliant label was rejected and several ways a field was misread, and the corrections are general: a warning read whose damage is made of the statutory words themselves (glued or broken statutory words, or a statement arriving as one- and two-word lines) is not readable wording and goes to review while text made of whole words that says something else is still a difference; a read that stops inside the first clause is a cut photograph, not a label missing its second clause; a contrast failure measured from a photograph rejects only when the ratio is below 2.0 or the read itself is weak, since capture flattens the contrast of medium-gray type that the OCR read with confidence; a web address is never the class statement; composition, color, code, web address, and tasting copy lines are never the brand; and a trademark mark read as letters is not part of the name. The evaluation harness prepares a photograph above the pixel limit the way the browser does and records, rather than aborts on, an image the production path refuses.

The same photographs set the time budget: a dense back label carries thirty or more small lines and its first recognition pass alone takes about five seconds, so the second, closer read is skipped when the first pass has used four seconds of OCR time, and the result lists that limitation; a product of three such photographs stays inside the nine-second hard-case budget and well inside the fifteen-second worker deadline instead of being terminated. The private end-to-end script now prepares oversized photographs the way the browser does and waits out the API's per-client start limit (sixty starts a minute) rather than recording a metered refusal as a failure, and the batch runner in the browser does the same for a large run of products.

A second independent review of those corrections found three over-corrections and they are reversed: the designation vocabulary now carries varietal, type, origin, and finishing words ("Pinot Noir", "Tequila Joven", "finished in port casks") so a designation is never the brand, and no class-bearing line is dropped in favour of another (two readings go to the reviewer); the line tokenizer of the edge rule sees the same text as the body it indexes, so a glued clause marker no longer disables it; an edge-cut opening may wrap after "According to the" and the two-word tail of the statement is warning text, not a brand; a disagreement between images needs a word with more than half its letters changed and is sought on every read, with both words named; a year is stripped only from a multi-word name; serving instructions are copy; and a fragment's heading row says the heading is outside the image.

A third review round and the full run over the store photographs closed the remaining gaps: an apostrophe no longer hides a vocabulary word ("Moscato d'Asti"), a line that opens with a wine designation or varietal names the wine, origin and finishing words do not split one designation into two, a garbled read is defined by statutory words fused together or cut at their start (an inflected real word such as "drinking" is a whole word, so replacement text stays a difference), a read of fewer than three words is not judged, a disagreement between images needs a real word and is sought symmetrically whichever photograph carried the heading, a fragment establishes a difference only when it shows twenty or more statutory words, a heading wrapped after "GOVERNMENT" is a heading in view, and names made of the statute's function words ("To the Moon") or ending in an integral year ("Old No 1888") remain brands.

An evaluation harness (`scripts/score_ground_truth.py`) processes every private test image, scores the 70 images with pixel-level field ground truth, and compares the 42 images covered by the disposition oracle. The runtime never reads either evaluation file, and no filename or expected value selects or overrides a runtime extraction or decision. Example product names may appear only in user guidance, fixtures, or generic grouping examples.

## Operational configuration

Environment settings control runtime mode, allowed host, client identity source, model root, spool root, history root, static root, sample manifest, and build ID. The default local history root is beneath the operating system temporary directory. Production uses the configured container filesystem unless a durable service is introduced at the system boundary.

The request contract uses a 15-second worker safety timeout inside the 30-second server boundary. Performance acceptance remains separate: about 5 seconds for typical work and no more than 9 seconds for difficult recoverable images.

The governed Azure Consumption deployment assigns 4 vCPU and 8 GiB to the single application replica. The workflow reads the effective resource configuration back from Azure and blocks the release if the allocation, immutable digest, or other deployment controls differ from the template.
