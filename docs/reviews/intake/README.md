# Intake Review History Notice

These files preserve the original Intake review history. Some reports use an earlier process interpretation that assigned architecture research and technical falsification to BAIRD.

The requester corrected the process definition in `EVT-014`:

- BAIRD validates the Intake, identifies what discovery defined and left undefined, and derives the complete requirements baseline needed for the intended experience.
- BAIRD defines what the solution must accomplish and what technical questions must be answered.
- I2R A&E owns architecture, engineering, feasibility research, stack, data flow, hosting, resource limits, and technical proof.
- FRD defines the exact features.
- BI defines work packages, ownership, standards, tests, QA/QC, UAT, and DoD.

The historical reports remain evidence of how the Intake was challenged. Their earlier downstream ownership statements are superseded by `docs/PROCESS.md`, `docs/intake/clarification-log.md` event `EVT-014`, and the current BAIRD.
