# LabelVerify Documentation Set

This documentation follows the controlled product path from discovery through release.

1. `01-discovery`: assignment and stakeholder baseline
2. `02-intake`: complete product requirements and success measures
3. `03-baird`: Beginning Assessment Intake Requirements Document
4. `04-i2r-ae`: Ideation-to-Realization architecture and engineering design
5. `05-frd`: feature requirements and traceability
6. `06-build-instructions`: build plan, work packages, tests, and Definition of Done
7. `07-development`: implemented component and interface record
8. `08-validation`: validation protocol, results, and objective evidence
9. `09-qa-qc-uat`: QA, QC, UAT, and defect-loop controls
10. `10-release`: release contents, deployment, and operational handoff
11. `11-federal-authorization-readiness`: federal authorization starter package

The source of truth for machine-enforced limits and rules is in `contracts/`. Product documentation explains those contracts and traces them to stakeholder needs.
